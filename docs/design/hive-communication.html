00 · Verification basis

Hive communication system

A present-tense map of runtime identity, observation, delivery, control, quota response, handoff, and ownership boundaries. Every factual claim carries the rung of evidence that stands behind it and, below the top rung, the exact check that would raise it.

No claim in this document sits at the live rung. None of the code mapped here has ever executed inside a running Hive daemon. Every rung below is a test, a real process, or a real binary — never a serving system.

The deployed system is not this source. The running daemon is build 1495d735; git rev-list --count 1495d735..main printed 66. The installed CLI is hive 0.0.38 (8ff0a55f, 2026-07-24, darwin-arm64); git rev-list --count 8ff0a55f..main printed 99. Any statement anyone makes about the deployed system describes those two builds, not this source. The skew is directly observable: hive status on the installed CLI fails to parse the running daemon's reply, rejecting the unrecognized keys holdReason and holdResetAt.

Evidence rungs

  • TESTAn in-process test exercises it. The row names the test.
  • PROCESSA real process, PTY, or signal was exercised. The row names it. This is strictly stronger than test and is never flattened into it.
  • VENDORA real vendor CLI or binary was in the loop. The row names the command and version. No row in this document reaches this rung.
  • LIVEObserved in a running Hive daemon serving real agents. No row in this document reaches this rung.
  • UNPROVENImplemented, with nothing exercising it at any rung. The row names the observation needed.
  • NOT IMPLEMENTEDThe row names the substitute that runs now and the concrete implementation needed.

  • TESTA measured reset within one hour pauses the exact run and stores held, reason, reset time, and held run ID.   • TESTResume first refreshes provider quota, then re-reads held state, active run ID, capability epoch, and verified foreground control.   • TESTA distant reset or an unmetered rate-limit error enters the handoff seam. Tests: the distant, all-drained, and unmetered cases in test/daemon/drain-handler.test.ts.Drain every live route and read the outcome: retained work plus an episodic memory row, no silent loss.
  • NOT IMPLEMENTEDAutomatic replacement excluding the drained pool is absent. replaceWithHandoff emits a durable notice with provider, pool, reset time, and handoff ID. Implementing replacement requires quota/selection ownership to enforce that exclusion and supply a replacement launch decision.Reading the notice on a live drain is the check: it carries no launch decision, and no replacement agent appears.

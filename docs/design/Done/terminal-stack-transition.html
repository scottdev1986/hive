00 · Verification basis

Hive terminal stack

An implementation map of the native host, PTY, process tree, Ghostty engine boundary, visibility lease, viewer protocol, replay surface, and teardown authority.

No claim in this document reaches the live rung. The running daemon reports build 1495d735, 86 commits behind source basis 22d211a3. The installed CLI reports hive 0.0.38 (8ff0a55f, 2026-07-24, darwin-arm64), 119 commits behind that basis. Source described here has not been observed in a serving daemon.

Two implementation facts require special care. The durable foreground-group target names the zsh group created with the terminal, not the provider currently in front of the PTY. Separately, a reparented owned process can escape the verified child tree between observations; teardown reports unknown, preserves observed member fates, and explicitly records that escapees are unaccounted. §§05 and 08 show the exact code and proof.
